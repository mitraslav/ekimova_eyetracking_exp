## После замены проекта выполните

```bash
python manage.py migrate
python manage.py runserver
```

Если раньше миграции приложения были созданы некорректно и база тестовая, можно удалить `db.sqlite3` и выполнить `python manage.py migrate` заново. Не делайте это, если в базе уже есть нужные данные.

## Если админка TrialResult всё ещё падает
Скопируйте полный traceback из терминала PyCharm или страницу ошибки Django. Наиболее вероятная причина — таблица `experiment_trialresult` ещё не создана миграцией.
